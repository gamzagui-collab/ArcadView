# 콘크리트 개략 적산 사용법

Arcad View 2.1.35(63) 내부 개발 빌드. 원본 DWG/DXF 파일은 변경하지 않습니다.

1. 도면을 열고 아래 툴바의 **적산**을 누릅니다. **적산 · …** 버튼으로 도구를 펼칩니다. 일반 그리기 레이어와 별개인 옹벽·보·슬래브·기둥 유형과 구역 레이어를 사용합니다.
2. **단위·스냅·부재 표시**에서 도면 1단위를 확인합니다. 단위를 알 수 없는 도면은 이 항목이 자동으로 펼쳐지며 mm/cm/m/in/ft를 직접 선택해야 확정할 수 있습니다. 저장 객체가 있는 상태에서 단위를 바꾸면 재계산 확인창이 표시됩니다.
3. **옹벽/보**는 중심선을 따라 스냅으로 점을 찍고 **완료**를 누릅니다. **슬래브**는 바닥 영역, **기둥**은 단면의 경계점을 찍고 완료하거나 시작점에 스냅하여 닫습니다. 자기 교차·면적 0인 영역은 확정할 수 없습니다.
4. 옹벽 높이(m 또는 mm)·두께(mm), 보 폭·깊이(mm), 슬래브 두께(mm), 기둥 높이(m 또는 mm)를 입력하고 **확정·저장**을 누릅니다. 이전 규격은 제안값이며 확인 전에는 저장되지 않습니다. 기둥 체적은 단면적 × 높이입니다.
5. **저장 완료**를 확인합니다. 개별 라벨, 유형별 길이/면적/체적, 우측 상단 전체 체적이 자동 갱신됩니다. 계산 정밀도를 유지하고 화면 표시에서만 반올림합니다.

도구 패널은 × 또는 **적산 · …** 버튼으로 접고 펼칠 수 있습니다. 합계 카드의 제목/⌃/⌄을 누르면 작은 한 줄로 접히거나 펼쳐집니다. 새 적산 문서는 접힌 합계로 시작하며 표시 상태를 기억합니다.

세로 화면의 적산 버튼은 왼쪽 끝, 실행취소/다시실행은 그 위에 있습니다. 가로 화면에서 폭이 충분하면 적산 버튼이 아래 툴바 X 오른쪽으로 들어갑니다. 상단 도면 헤더는 높이 44px(안전 영역 제외)입니다.

## 구역별 레이어

왼쪽 위 **적1/적2…**를 눌러 레이어 창을 엽니다. **그리기 / 적산** 탭으로 나누어 관리합니다. 그리기 탭에서 끈 일반 주석 레이어는 적산 중에도 숨겨진 상태가 유지됩니다.

- 적산 탭에서 레이어를 추가하고 이름을 `2동 1·2호`, `2동 3·4·5호`처럼 바꿉니다. 이름은 입력 후 다른 곳을 누르거나 Enter를 누르면 저장됩니다.
- 라디오 버튼으로 현재 적산 레이어를 선택합니다. 새 객체는 선택한 구역에만 저장됩니다. 한 구역에 옹벽·보·슬래브·기둥을 함께 그릴 수 있습니다.
- 표시 체크를 끄면 그 구역의 적산선·면과 스냅 대상만 숨겨집니다. 저장된 물량과 전체 합계는 유지됩니다.
- 각 행에 객체 수, 길이, 면적, 체적이 표시됩니다. 합계 카드에는 전체, 현재 표시 중인 부분, 현재 선택한 구역의 합계를 구분합니다.
- 레이어를 삭제하면 그 안의 적산 객체도 함께 삭제되므로 확인창이 뜹니다. 적산 실행취소/다시실행으로 레이어와 객체·물량을 함께 복원할 수 있습니다.
- 기존 2.1.31 적산은 `적산 1` 구역으로 자동 이전됩니다. 기존 좌표·규격·라벨과 계산값은 유지됩니다. 일반 그리기 레이어의 최대 3개 제한과 분리됩니다.

## 수정과 표시

- **선택**으로 적산 경계선을 누릅니다. 객체 ID, 규격 수정, 점 추가/삭제, 라벨 숨김, 객체 삭제가 표시됩니다.
- 꼭짓점의 작은 흰 점과 원을 드래그하면 형상을 수정합니다. 점 추가 후에는 원하는 위치를 찍습니다. 꼭짓점을 선택한 후 선택 점 삭제를 사용할 수 있습니다.
- 십자 손잡이는 객체 전체 이동입니다. 스냅을 켜면 CAD 및 표시된 적산 객체에 맞출 수 있습니다. 길이·면적은 이동으로 바뀌지 않습니다.
- 라벨 상자를 드래그하면 숫자 위치만 바뀝니다. 꼭짓점과 규격은 유지합니다. 겹치는 라벨은 수동으로 옮길 수 있습니다.
- 객체 라벨은 `12.000 m³`처럼 한 줄로 작게 표시됩니다(글자 10px, 박스 높이 22px). 상세 규격은 객체를 선택해 **규격 수정**에서 확인하며, 짧은 ID는 선택한 객체에만 표시됩니다.
- 하단 적산 상태 옆 **물량** 버튼으로 모든 객체 라벨·박스·연결선을 한 번에 숨기거나 다시 표시합니다. 적산선·면과 계산값·합계는 유지됩니다. 도면별로 설정을 기억하며, 개별 객체에서 숨겼던 라벨은 전체 표시를 켜도 숨김 상태를 유지합니다.
- 왼쪽 Undo/Redo는 현재 적산 작업의 형상·규격·집계를 함께 복원합니다. 일반 주석의 Undo/Redo와 분리됩니다.
- 그룹의 표시 체크와 색상을 바꿀 수 있습니다. 그룹을 숨겨도 **전체 총합**은 유지되며 **현재 표시 그룹** 합계를 별도로 표시합니다.
- **집중 보기**를 켜면 원본 CAD를 회색으로 표시합니다. 바로 아래 색상 팔레트에서 선택한 색만 원래 색상을 유지합니다. **도면 객체에서 색상 선택**을 누른 뒤 원본 선·면을 누르면 회색으로 보이던 객체의 원래 색을 가져옵니다. 빈 곳은 다시 선택하며 × 또는 도구 해제로 취소합니다. 원본 도면 표시가 꺼져 있으면 이 기능도 사용할 수 없습니다. 여러 색을 선택할 수 있으며 적산 객체의 색상은 유지됩니다. 적산 모드를 종료하면 CAD 원래 색상으로 복원됩니다.
- **원본 도면** 체크를 끄면 CAD 배경만 숨깁니다. 적산선·면, 일반 그리기 주석과 확대/이동은 유지됩니다. 숨겨진 원본 객체에는 스냅하지 않습니다. 적산 모드를 나가면 원본이 다시 보이며 이 표시 옵션은 다음 적산 진입 때 적용됩니다.

선택한 적산 객체의 **적산 레이어** 목록에서 소속을 변경할 수 있습니다. 좌표·규격·라벨·전체 물량은 유지되고 구역별 합계가 바로 바뀝니다. 숨긴 레이어로 옮기면 선택이 해제되고 해당 객체가 숨겨집니다. 대상 레이어를 표시하면 다시 나타나며 실행취소·다시실행도 지원합니다.

## 저장과 도면 개정

적산은 기기 내부의 별도 IndexedDB(`arcad-concrete-takeoff`, DB/문서 스키마 3)에 자동 저장됩니다. 좌표·규격·단위·유형·구역 레이어·라벨·표시 설정을 저장하고 계산 결과는 그 자료에서 다시 계산합니다. 앱을 완전히 종료한 후 같은 도면을 열어도 복원됩니다. 이전 스키마 1·2 자료는 하나의 트랜잭션으로 이전하며 오류 시 이전 전체를 취소하고 기존 자료를 보존합니다. 스키마 2에서는 기둥 표시 그룹·기본 높이만 추가하며 기존 객체·규격·레이어는 유지합니다.

도면 전체 내용을 반영한 식별자로 연결합니다. 같은 파일명이라도 내용이 바뀌면 이전 적산을 자동 적용하지 않고 **새 도면으로 적산 시작** 확인을 요청합니다. 이전 적산은 이전 내용 식별자에 보존됩니다. 새 도면 확인은 저장되어 다음 재열기 때 반복하지 않습니다.

저장 오류가 나면 기존 저장값과 합계를 유지하고 오류·재시도·변경 취소를 표시합니다. 저장 완료를 확인해 주세요. 이 버전은 별도 클라우드 백업이나 적산 JSON 내보내기를 제공하지 않습니다. 앱 삭제/데이터 초기화는 로컬 적산을 잃게 할 수 있습니다.

## 계산 범위

| 유형 | 계산 |
| --- | --- |
| 옹벽 | 중심선 총길이(m) × 높이(m) × 두께(m) |
| 보 | 중심선 총길이(m) × 폭(m) × 깊이(m) |
| 슬래브 | 폐합 영역 면적(m²) × 두께(m) |
| 기둥 | 폐합 단면적(m²) × 높이(m) |

## Excel 물량집계 다운로드

적산 도구 또는 레이어 창의 **적산** 탭에서 **Excel 집계표**를 누릅니다. 저장이 끝난 객체만 집계하며 숨긴 레이어·부재도 전체 물량에 포함합니다. 작성 중인 점이나 아직 확정하지 않은 규격은 포함하지 않습니다.

Android에서는 저장 위치를 선택하고 **저장**을 누릅니다. 파일 이름은 `도면이름_물량집계.xlsx`입니다. 파일 기록이 완료되어야 앱에 저장 완료가 표시됩니다. 뒤로가기로 취소하면 재시도할 수 있고, 저장 공간·위치 문제는 오류로 표시됩니다. 브라우저에서는 다운로드가 시작됩니다. 내보내기는 원본 도면과 저장된 적산·토큰을 변경하지 않으며 인터넷 연결이 필요하지 않습니다.

**물량집계** 시트 제목은 원본 도면명이며 다음 6열을 사용합니다. 모든 길이는 m, 체적은 m³입니다.

| 레이어 이름 | 부재 | 길이 | 너비 | 높이 | 체적 |
| --- | --- | --- | --- | --- | --- |
| 구역명 | 옹벽 | 중심선 총길이 | 빈칸 | 높이 | 길이 × 높이 × 두께 |
| 구역명 | 보 | 중심선 총길이 | 폭 | 깊이 | 길이 × 폭 × 깊이 |
| 구역명 | 슬래브 | 대표 변 | 면적 ÷ 대표 변 | 빈칸 | 면적 × 두께 |
| 구역명 | 기둥 | 단면 대표 변 | 단면적 ÷ 대표 변 | 높이 | 단면적 × 높이 |

- 각 객체를 한 행씩 기록한 뒤, 레이어 안의 부재별 소계와 레이어 합계를 표시합니다. 마지막에는 도면 전체 부재별 총계와 모든 레이어의 전체 총계를 표시합니다. 소계·합계를 중복 합산하지 않습니다.
- 슬래브·기둥의 대표 변은 가장 긴 경계 변입니다. 직사각형은 실제 가로·세로가 되며 자유형은 **대표 변·환산 너비**로 표시합니다. 환산 너비는 실제 경계 폭을 뜻하지 않습니다.
- 별도 **산출근거** 시트에 객체 ID, 실제 면적, 옹벽·슬래브 두께, 기둥 높이, 보 폭·깊이, 실제/환산 구분과 숨김 여부를 기록합니다. 따라서 6열에서 생략한 두께도 검산할 수 있습니다.
- 객체 체적과 소계·합계에는 Excel 수식을 넣습니다. 산출근거의 규격을 수정하면 Excel에서 재계산됩니다. 앱의 원래 적산 데이터는 바뀌지 않습니다. 화면 표시는 소수점 3자리이며 수식에는 원래 정밀도를 유지합니다.

Excel은 집계 자료이며 앱 재가져오기용 백업 파일은 아닙니다.

결과는 **중첩·개구부 공제 전 개략 체적**입니다. 교차 옹벽, 보·슬래브·기둥 중첩, 개구부, 코너 체적 차이, 경사·높이 변화를 자동 공제하지 않습니다. 같은 부위를 여러 번 그리면 중복 합산되므로 ID와 그룹을 확인해 주세요.

적산은 기존 로그인·토큰·구독 정책에 연결하지 않았습니다. 확정 후의 로컬 완료 이벤트만 분리했으며 실제 사용량 차감이나 결제 요청은 발생하지 않습니다.

검증 결과와 다음 작업은 [개발 체크포인트](TAKEOFF_DEVELOPMENT_CHECKPOINT.md)를 참조하세요. 직원용 GitHub 릴리스는 v2.1.33 (61)이며 Google Play 배포와 실제 과금은 변경하지 않았습니다.
