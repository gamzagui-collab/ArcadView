# 블록·해치 스냅

측정 및 그리기 창의 기존 스냅 옵션을 켜면 블록 내부 도형과 해치 경계에도 같은 스냅이 적용됩니다. 길게 눌러 손가락 위의 조준점을 이동한 뒤 손을 떼면 해당 좌표를 확정합니다. 이동 도구의 기준점과 목적점에서도 사용할 수 있습니다.

- 블록: 내부 도형의 지원되는 끝점·중간점·중심점 및 블록 삽입점. 중첩·회전·축척·반전을 반영합니다.
- 해치: 경계 끝점·중간점, 원호·타원의 중심과 기준점, 직선 경계의 수직 발. 곡선 끝점은 화면 렌더러의 보간을 사용합니다.
- XCLIP으로 가려진 스냅 좌표와 경계 구간은 제외합니다. 해치 내부 장식 패턴의 개별 획은 스냅 대상으로 만들지 않습니다.

원본 DWG/DXF는 변경하지 않습니다. 새 스냅 좌표는 기존 측정 인덱스와 별도의 제한된 버퍼에 보관하므로 기존 거리·면적 측정 자료를 밀어내지 않습니다. 추가 인덱스가 한도를 초과하면 기존 안내가 표시됩니다.

업데이트 후 처음 열 때 새 스냅 인덱스를 한 번 준비합니다. 이미 변환한 DWG의 DXF 캐시는 그대로 사용하며, 이후에는 저장한 화면·스냅 캐시를 다시 사용합니다. 앱 데이터 삭제 없이 APK를 업데이트하세요.
