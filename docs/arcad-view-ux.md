# Arcad View UX

Arcad View / GUI's Arc Industry의 현장용 CAD 열람·측정·마크업 화면입니다. 기존 원본 도면, 오프라인 동작, 주석과 단위 저장 형식을 유지합니다.

- 홈: 남색 브랜드 헤더, 건축 선화, 실제 최근 도면, 보관함 바로가기. 작은 파일도 B/KB/MB 단위로 표시합니다.
- 보관함: 밝은 목록, 검색·정렬·폴더 관리·압축 가져오기 등 기존 기능을 유지합니다.
- 뷰어: 남색 헤더와 아래 도구바, 파란 선택 상태, 접을 수 있는 측정창과 도구 상태 표시.
- 보기 기능 4개는 작은 아이콘 그룹입니다. 좁은 화면에서는 2×2로 배치하며 각 아이콘의 접근성 이름과 툴팁을 유지합니다.
- 그리기 옆의 세 아이콘은 실행 취소 / 다시 실행 / 도구 해제입니다. 해제는 진행 중 지점 선택과 도구를 종료하며 저장된 객체는 지우지 않습니다. 측정 중에는 측정 지점, 그리기 중에는 지점·주석 편집 기록에 적용됩니다.
- 텍스트는 도면에서 길게 눌러 조준점을 이동한 후 손을 떼면 바로 입력합니다. 짧게 눌러 위치를 지정할 수도 있습니다. 입력창 바깥의 도면을 누르면 완료되며 같은 터치로 새 문자를 찍지 않습니다. 기존 주석 문자를 길게 누르면 다시 편집합니다.
- 텍스트 입력에는 브라우저의 실제 입력창을 사용합니다. 한글 조합 중인 글자도 즉시 표시하고, 완료 시 마지막 조합 값을 읽습니다. 왼쪽 슬라이더로 크기를 조절하며 그 아래 팔레트 버튼에서 색을 고른 후 적용합니다. 색상은 객체별로 저장하고 지정하지 않은 문자는 기존 레이어 색상을 따릅니다.
- 한 번의 텍스트 편집은 내용·크기·색상을 묶어 한 번에 실행 취소합니다. 주석 편집 기록은 메모리에 최대 30개를 유지하며, 앱을 다시 실행하면 기록은 비워지고 저장한 객체는 유지됩니다.
- 작업창: 레이어 / 그리기 / 치수 탭. 탭 변경과 창 접기는 선택 도구·스냅·배율을 초기화하지 않습니다. 사용법은 펼쳐 볼 수 있습니다.
- 브랜딩: 앱 표시 이름과 Android 아이콘은 Arcad View입니다. 업데이트 호환성을 위해 applicationId와 기존 저장소 키는 유지합니다. 원본 오픈소스 고지는 앱 정보에서 오프라인으로 열람할 수 있습니다.

Android 빌드: `npm ci`, `npm test`, `npm run android:prepare`, `android/gradlew.bat -p android assembleDebug`.

UI 로고와 건축 선화는 SVG/Android VectorDrawable로 구현하여 인터넷 없이 사용할 수 있습니다. 도면 엔진과 DWG 변환/화면 캐시 버전은 이 UX 변경에서 수정하지 않습니다.
