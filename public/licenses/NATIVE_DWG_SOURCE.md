# LibreDWG native source

`libredwg-0.9.0-source.tar.gz` contains the unmodified C library, public headers,
build helpers, CMake configuration and license from mlightcad/libredwg-web v0.9.0,
commit `7d90153180229faff5d1bbdfb9fb4378d5f141d5` (GPL-3.0-or-later).
This is the same engine version as the existing WASM converter. No user drawings
or upstream test drawings are included. The archive is bundled for offline,
reproducible builds and corresponding source distribution.
